# 🔍 GitHub Profile Analyzer

A modern web application that analyzes GitHub profiles and displays useful insights such as repositories, followers, following count, and developer statistics using the GitHub API.

This project demonstrates the use of **REST APIs, asynchronous JavaScript, and responsive UI design** to build an interactive developer tool.

---

## 🚀 Live Demo

(https://github-profile-analyzer-gold.vercel.app/?user=Thanvika-gali)

---

## 📌 Features

* 🔎 Search any GitHub username
* 📊 View public repository count
* 👥 Display followers and following
* ⭐ Show profile statistics and details
* ⚡ Fast API data fetching
* 🎨 Clean and responsive UI
* 🌙 Dark / Light theme toggle
* ❗ Error handling for invalid usernames

## ⚙️ Installation & Setup

Clone the repository:

```
git clone https://github.com/your-username/GitHub-Profile-Analyzer.git
```

Navigate to the project directory:

```
cd GitHub-Profile-Analyzer
```

Open `index.html` in your browser.

---

## 📡 How It Works

1. User enters a GitHub username.
2. The application sends a request to the GitHub API.
3. Profile data is fetched asynchronously.
4. The UI updates dynamically with the fetched data.

Example API endpoint:

```
https://api.github.com/users/{username}
```
